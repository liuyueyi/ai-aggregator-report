#### 10. RAPID: Robot Agentic Programming from Demonstrations
- **来源**: arXiv | **时间**: 2026-09-24
- **摘要**: RAPID: Robot Agentic Programming from Demonstrations
- **深度洞察**: RAPID 自动生成、验证和优化机器人程序，基于单个视觉人类演示。通过移除需要从头开始去噪整个预测地平线的需求，它实现了标准联合 WAM 的4.5倍稳定状态重规划速度。该方法通过在连续重规划周期中分布联合去噪过程，维护一个滑动窗口的视频-动作块，允许在每个步骤中完全去噪即将执行的动作块，同时部分优化更远未来块。

#### 11. JevOut: Natural Context Can Flip Decision Models
- **来源**: arXiv | **时间**: 2026-09-24
- **摘要**: JevOut: Natural Context Can Flip Decision Models
- **深度洞察**: 研究表明，自然上下文的短添加可以改变模型的决策结果，即使正确答案保持不变。通过在模型输出中固定错误选项，研究者发现优化器可以识别能够将Jev导向错误决策的上下文。这些结果暴露了当前决策模型的显著脆弱性：短而普通的上下文可以将正确选择转向高置信度的错误选择。

#### 12. SemMSA: Latent Semantic-Aided Robust Multimodal Sentiment Analysis with Incomplete Data
- **来源**: arXiv | **时间**: 2026-09-24
- **摘要**: SemMSA: Latent Semantic-Aided Robust Multimodal Sentiment Analysis with Incomplete Data
- **深度洞察**: SemMSA 是一个基于潜在语义辅助的框架，通过LLMs构建丰富的语义，并使用无锚点谱对齐，完全整合所有模态。它主要包含跨模态语义细化（CSR）和跨模态谱对齐（CSA）。CSR 通过适配器适配视觉和声学表示形成统一的多模态前缀，然后通过令牌高效的潜在细化过程迭代生成连续的判别语义状态，而无需解码显式文本。CSA 通过增强其核Gram矩阵的主导谱分量，同时对齐细化后的语义与所有模态，捕捉所有表示之间的全局非线性依赖，而无需依赖预定义的锚定模态。
